# Публикация портфолио на GitHub Pages

Архив содержит готовый статический сайт. Для открытия и публикации не нужны
Node.js, npm, сервер или установка библиотек.

## Сначала открыть локально

1. Полностью распакуй архив в отдельную папку.
2. Открой `index.html` в браузере.
3. Перейди в три подробных кейса и на страницу Experience. Проверь скачивание
   PDF и Word и кнопку Show retry path в AI-схеме.

Все материалы сайта находятся в архиве. Отдельный HTML-файл, выданный вместе
с архивом, позволяет посмотреть все страницы без распаковки, но для публикации
используй именно содержимое ZIP.

## Основной адрес: jeyboy.github.io

1. Войди в GitHub под аккаунтом `jeyboy`.
2. Проверь, существует ли репозиторий `jeyboy.github.io`. Если он уже используется,
   сначала проверь его содержимое. Если его нет — создай публичный репозиторий
   с таким именем.
3. Загрузи содержимое архива в корень ветки `main`. Файл `index.html` должен
   находиться непосредственно в корне, рядом со `styles.css` и папкой `assets`.
4. Проверь, что загружен пустой файл `.nojekyll`. При необходимости создай его
   через **Add file → Create new file**.
5. В **Settings → Pages** выбери **Deploy from a branch**, ветку **main** и
   папку **/ (root)**, затем **Save**.
6. Дождись завершения публикации и открой `https://jeyboy.github.io/`.

## Другой репозиторий или свой домен

В `site.json` укажи нужный адрес в поле `url`, например:

```json
"url": "https://jeyboy.github.io/portfolio/"
```

Затем пересобери страницы из папки сайта:

```text
py tools/build.py
py tools/check.py
```

В Windows обычно работает `py`; также можно использовать `python` или `python3`.
Нужен Python 3.9 или новее, без дополнительных пакетов. Пересборка обновит
канонические адреса, sitemap, robots.txt и ссылки страницы 404.

## Что можно менять

- Тексты и даты — в `src/home.html`, `src/experience.html` и файлах кейсов.
- Общую шапку и подвал — в `src/template.html`.
- Контакты — в `src/contact.html`; данные для поисковых систем — в `site.json`.
- Цвета — в блоке `:root` файла `styles.css`.
- Оформление подробных страниц — в `pages.css`.
- CV — заменить файлы в `assets`, сохранив их имена.

После изменений в `src` повторно запусти `tools/build.py` и загрузи обновлённые
файлы. Сам сайт работает без Python и JavaScript; JavaScript добавляет
переключение примера в AI-схеме.

Статические проверки выполнены. Визуальное отображение в браузере и поведение
на телефоне в этой среде не проверялись: перед публикацией просмотри сайт
в своём браузере и в узком окне, включая навигацию клавишей Tab.

Официальная инструкция: [Creating a GitHub Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).
